# Oficina de robots

Pagina independiente (un solo archivo, index.html) que muestra a los robots como personajes en una oficina isometrica.
No modifica nada del resto del repo.

- Abrir: doble clic en index.html (o python -m http.server dentro de esta carpeta).
- Modo DEMO: datos inventados, para ver como se ve.
- Modo REAL: boton "Ver datos reales" + la clave del panel. Lee el mismo datos.json cifrado que ya publica el panel y lo descifra en el navegador; la clave no se guarda ni se envia a ningun lado.
- Cada escritorio = un robot (cara segun su resultado, pantalla con su valor en el tiempo). Tocarlo muestra su ficha.
- Salas: Noticias y analisis, Guardian de riesgo (con kill switch), Comite y bitacora.
